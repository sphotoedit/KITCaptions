# Contributing to KITCaptions

Thanks for helping improve KITCaptions.

## Quick start

- The app is a single static file: `KITCaptions.html`.
- Open it in a recent browser, or serve the folder on `localhost` for browser features that need a secure context.
- No build tools or package installation are required.
- Do not commit API keys, personal videos, transcripts, or other private data.

## Changes

Keep edits focused and describe the user-facing result in your pull request. Include a screenshot for visible interface changes when possible. Please check that the editor still opens, media and subtitle import remain available, and the main timeline interactions still work.
